# Finnomena Fund Screener (ระบบเปรียบเทียบกองทุนรวมไทย)

เครื่องมือสำหรับคัดกรองและเปรียบเทียบกองทุนรวมไทย ทำงานได้ทั้งแบบ **Offline 100%** และสามารถ **กดปุ่มอัพเดทข้อมูลล่าสุดจาก Finnomena ได้ตลอดเวลา**

---

## ✨ ฟีเจอร์เด่นใหม่: Smart Comparison & Class Matcher

### 1. 🏆 ตัวค้นหากองแม่ค่าธรรมเนียมต่ำสุด (Same Master Fund / Best Fee Finder)
- **ปุ่มด่วน "🏆 Best Fee Finder" ในแถบเครื่องมือ:** คลิกเพื่อเลือกกลุ่มดัชนีหรือ ETF ยอดนิยม (`QQQ`, `S&P 500`, `GLD ทองคำ`, `Semicon`, `ACWI`, `Nikkei`, `CapGroup`, `PIMCO` ฯลฯ)
- **ปุ่ม "🏆 เทียบ บลจ." ในตารางหลัก:** อยู่ข้างป้ายกองแม่ทุกกอง คลิกเพื่อเปิดตารางเปรียบเทียบทุก บลจ. ที่ลงทุนในกองแม่เดียวกันได้ทันที
- **สรุปผลวิเคราะห์ความคุ้มค่า (Insights Cards):**
  - 🥇 **TER รวมถูกที่สุด:** ชี้เป้ากองทุนและ บลจ. ที่คิดค่าธรรมเนียมต่ำที่สุดทันที (เช่น SCBAM/KKP ใน QQQ เพียง 0.09% - 0.10%)
  - 🛡 **Hedged ถูกที่สุด:** กองที่ป้องกันความเสี่ยงค่าเงินที่ TER ต่ำสุด
  - ⚡ **Unhedged ถูกที่สุด:** กองที่ไม่ป้องกันค่าเงินที่ TER ต่ำสุด
  - 💰 **ส่วนต่างที่ประหยัดได้ (%/ปี):** คำนวณความต่างของค่าธรรมเนียมระหว่าง บลจ. ที่ถูกสุด vs แพงสุด
- **ตารางเปรียบเทียบจัดอันดับตาม TER (🥇 🥈 🥉):**
  - กรองแยกแท็บได้ทันที: `ทั้งหมด`, `🛡 ป้องกันค่าเงิน`, `⚡ ไม่ป้องกันค่าเงิน`, `⚡ E-Class`, `🧾 ลดหย่อนภาษี SSF/RMF`
  - ส่งออกตารางเปรียบเทียบนี้เป็นไฟล์ CSV ได้โดยตรง

### 2. 🔗 จับคู่หน่วยลงทุนแฝด (Share Class Matcher)
- **ป้ายเตือนอัตโนมัติในตารางหลัก:**
  - `⚡มี E-Class` : แจ้งเตือนเมื่อกองทุนนี้มีแฝดที่เป็น E-Class (ฟรีค่าจัดการ)
  - `🧾มีลดหย่อน` : แจ้งเตือนเมื่อกองทุนนี้มีแฝดสำหรับลดหย่อนภาษี (SSF / RMF / ThaiESG)
- **ระบบวิเคราะห์ในหน้ารายละเอียดกองทุน (Modal):**
  - ⚡ **กล่องแจ้งเตือนประหยัดค่าธรรมเนียม:** คำนวณให้ทันทีว่าหากเปลี่ยนไปซื้อแฝด E-Class จะประหยัด TER ได้กี่ % ต่อปี พร้อมปุ่มกดสลับไปดูทันที
  - 🧾 **กล่องแนะนำลดหย่อนภาษี:** แนะนำเวอร์ชัน SSF/RMF ของกองทุนนี้สำหรับวางแผนภาษี
  - **ตารางเปรียบเทียบแฝดทุกชนิด (Share Classes Table):** แสดงทุกคลาสของกองนี้ พร้อมเปรียบเทียบส่วนต่าง TER (ถูกกว่า/แพงกว่า) และค่าธรรมเนียมซื้อ Front-end


### 3. 🧠 ระบบค้นหาอัจฉริยะ (Smart Multi-Search)
- **พิมพ์เงื่อนไขผสมหลายมิติในช่องเดียว:** เช่น:
  - `rmf tech unhedge` : ค้นหากอง RMF หมวดเทคโนโลยี ที่ไม่ป้องกันค่าเงิน
  - `ssf semicon` : ค้นหากอง SSF เซมิคอนดักเตอร์ (พบทันที 3 กอง)
  - `qqq e-class` : ค้นหากอง QQQ ที่เป็น E-Class ฟรีค่าจัดการ
  - `sp500 unhedge` : ค้นหากอง S&P 500 ไม่ป้องกันค่าเงิน
  - `scb gold ปันผล` : ค้นหากองทองคำ บลจ. ไทยพาณิชย์ ที่มีปันผล
- **แถบถอดรหัสคำค้นหา (Search Token Bar):** แสดงป้ายเงื่อนไขที่ระบบตีความได้ พร้อมปุ่ม ✕ สำหรับปลดเงื่อนไขทีละข้อ

### 4. 💡 ตัวแนะนำทางเลือกเมื่อไม่พบกองทุน (Smart Alternative Recommender)
- **แก้ปัญหา Pain Point สำคัญ:** ในกรณีที่ผู้ใช้ค้นหาเงื่อนไขที่ไม่มีกองทุนในไทย เช่น `RMF Semicon` (ในตลาดไทยไม่มี บลจ. ไหนทำ RMF ที่ลง ETF ชิปโดยตรง)
- ระบบจะไม่แสดงหน้าจอว่างเปล่า แต่จะวิเคราะห์และแนะนำทางเลือกที่ถูกต้องตามกฎหมายภาษีปี 2569 ทันที:
  - 🏔️ **แนะนำกอง RMF หมวดเทคโนโลยี & AI:** สำหรับผู้ที่ต้องการลดหย่อนภาษีปี 2569 ในกลุ่มอุตสาหกรรมเทคโนโลยี (เช่น `K-GTECHRMF`, `B-ASIATECHRMF`, `ASP-AIEQRMF`)
  - ⚡ **แนะนำกอง Semicon ทั่วไป & E-Class:** สำหรับผู้ที่ต้องการลงทุนในอุตสาหกรรมชิปโดยตรง ฟรีค่าธรรมเนียมจัดการ (เช่น `SCBSEMI(E)` TER 0.10%)
  - 📦 **แจ้งเตือนเงื่อนไข SSF:** มีกอง SSF Semicon สำหรับผู้มีพอร์ตเดิมที่ต้องการสับเปลี่ยน (Switching) เท่านั้น *(เนื่องจากกองทุน SSF สิ้นสุดสิทธิ์ลดหย่อนภาษีซื้อใหม่ตั้งแต่สิ้นปี 2567)*
- พร้อมปุ่มกดสลับเงื่อนไขได้ทันทีในคลิกเดียว

### 5. 🧙 ตัวช่วยค้นหากองทุนแบบ Step-by-Step (Fund Wizard)
- **ปุ่ม "🧙 Fund Wizard" บนแถบเครื่องมือ:**
  - **ขั้นที่ 1: เป้าหมายการลงทุน** (ทั่วไป / RMF ลดหย่อนภาษีเกษียณ / ThaiESG ลดหย่อนภาษี 5 ปี / E-Class ฟรีค่าจัดการ / SSF พอร์ตเดิม / ไม่จำกัด)
  - **ขั้นที่ 2: สินทรัพย์ / ธีม** (Nasdaq QQQ / Semicon / S&P 500 / ทองคำ / ญี่ปุ่น Nikkei / ทุกธีม)
  - **ขั้นที่ 3: นโยบาย FX** (ป้องกันค่าเงิน / ไม่ป้องกัน / ไม่จำกัด)
- **ผลลัพธ์:** จัดอันดับกองทุนที่ตรงโจทย์เรียงตามค่าธรรมเนียม **TER ต่ำที่สุดก่อนเสมอ (Lowest Fee First)** หรือแนะนำทางเลือกอย่างชาญฉลาดหากไม่มีกองที่ตรงเป๊ะ

### 6. ⚡ ปุ่มลัดสถานการณ์ยอดนิยม (One-Click Preset Strip)
- แถบปุ่มลัดด้านบนตาราง เรียกดูสถานการณ์ที่นักลงทุนค้นหาบ่อยได้ในคลิกเดียว:
  - `⚡ ETF ไม่ป้องกัน FX` : กองทุนไทยที่เป็น ETF Feeder Fund และไม่ป้องกันความเสี่ยงค่าเงิน (Unhedged FX) ทั้งหมด
  - `🏔️ RMF หุ้นนอก` : คัดเฉพาะ RMF สินทรัพย์ต่างประเทศ
  - `💻 RMF เทคโนโลยี` : RMF หมวดเทคโนโลยี (ลดหย่อนภาษีปี 2569)
  - `🌿 ThaiESG (ลดหย่อน 5 ปี)` : กองทุน ThaiESG ลดหย่อนภาษีเกณฑ์ใหม่
  - `🔬 Semicon ไม่ป้องกัน` : กองทุนเซมิคอนดักเตอร์แบบ Unhedged FX
  - `🥇 กองทุนทองคำ` : กองทุนทองคำทุก บลจ.
  - `⚡ E-Class ทุก บลจ.` : รวมกองทุน E-Class ฟรีค่าจัดการ
  - `📈 QQQ ทุก บลจ.` : เปรียบเทียบกองทุน Nasdaq 100 ทุกค่าย
  - `🇺🇸 S&P500 ไม่ป้องกัน` : S&P 500 แบบ Unhedged FX
  - `💰 RMF TER ต่ำสุด` : คัดกองทุน RMF เรียงตามค่าธรรมเนียมต่ำสุด
  - `📦 SSF เทคโนโลยี (พอร์ตเดิม)` : กองทุน SSF สำหรับสับเปลี่ยนพอร์ตเดิม

## 🚀 วิธีการใช้งาน

### วิธีที่ 1: ใช้งานแบบเต็มระบบ (แนะนำ — กดปุ่มอัพเดทบนหน้าเว็บได้)
1. ดับเบิ้ลคลิกไฟล์ **`start_screener.bat`**
2. ระบบจะเปิดหน้าเว็บ `http://localhost:8080/index.html` ขึ้นมาให้อัตโนมัติ (มีไฟสถานะ 🟢 `พร้อมอัพเดท`)
3. เมื่อต้องการอัพเดทข้อมูล: ให้คลิกปุ่ม **"🔄 อัพเดทข้อมูล"** ด้านขวาบนของตาราง
   - หน้าต่างจะแสดงแถบเปอร์เซ็นต์ความคืบหน้าแบบ Real-time
   - เมื่ออัพเดทเสร็จแล้ว ข้อมูลจะถูกบันทึกเก็บไว้ใน `index.html` อัตโนมัติ

### วิธีที่ 2: ใช้งานแบบ Offline ล้วนๆ (ไม่ต้องเปิด Server)
1. ดับเบิ้ลคลิกเปิดไฟล์ **`index.html`** ได้ทันทีในเบราว์เซอร์ใดก็ได้
2. สามารถค้นหา, กรอง, เรียงลำดับ, กราฟเปรียบเทียบ ได้ตามปกติโดยไม่ต้องต่ออินเทอร์เน็ต

### วิธีที่ 3: อัพเดทข้อมูลผ่าน Batch file โดยตรง
1. ดับเบิ้ลคลิกไฟล์ **`อัพเดทข้อมูล.bat`** (หรือ `update_data.bat`)
2. รอระบบดึงข้อมูลประมาณ 10–20 วินาที
3. เมื่อเสร็จสิ้น หน้าต่างจะสรุปจำนวนกองทุนทั้งหมดและจำนวนกองทุนใหม่ที่เพิ่มเข้ามา
